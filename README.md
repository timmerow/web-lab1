# Домашняя страница

Первая лабораторная работа по основам веб-технологий.

Автор: Богданов Тимофей Александрович.

## Файлы

- `index.html` — содержимое страницы: шапка, меню, разделы, фотография, таблица и футер.
- `style.css` — оформление страницы. Комментарии разделяют стили на понятные группы.
- `images/workspace.jpg` — фотография рабочего места.

Шрифт Roboto подключён через Google Fonts. Для его загрузки нужен интернет.

Фотография: [Radek Grzybowski, Laptop on a desk](https://commons.wikimedia.org/wiki/File:Laptop_on_a_desk.jpg), лицензия [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

## Ссылки для сдачи

- Репозиторий: https://github.com/timmerow/web-lab1
- Сайт: https://timmerow.github.io/web-lab1/

## Как открыть

Открыть `index.html` в браузере. Установка дополнительных программ и сборка не нужны.

## Как работает меню

Ссылка `href="#about"` ведёт к разделу с `id="about"`.
По тому же принципу работают ссылки на учёбу и контакты.
